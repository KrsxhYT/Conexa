# Conexa

**Premium Contacts App** — Clean, fast, and beautiful contact management inspired by iOS Contacts.

![Platform](https://img.shields.io/badge/Platform-Android-green)
![Language](https://img.shields.io/badge/Language-Java-orange)
![UI](https://img.shields.io/badge/UI-iOS%20Style-blue)

---

## Features

### Core
- Beautiful contact list with alphabetical section headers
- Smart search (name, phone, email)
- Favorites with horizontal scroll avatars
- Quick call action from list
- Contact detail view with phones, emails, organization
- Add new contacts via system contacts app
- Profile & Settings screens

### UI / UX (Premium iOS Style)
- Refined color system matching iOS design language
- Large, bold titles with proper letter-spacing
- Soft search pill
- Clean bottom navigation
- Haptic feedback on interactions
- Smooth empty & permission states
- High-quality avatar initials with colorful backgrounds

### Recent Improvements (v2.0)
- Full color system upgrade (iOS-accurate blues, grays, accents)
- Improved typography and spacing throughout
- Better empty states and search result messaging
- Haptic feedback on buttons & navigation
- Favorites limited to 12 for performance & cleanliness
- Soft refresh on resume
- Polished strings and accessibility labels
- Refined bottom navigation
